    Download Duckky Client

    Windows

    Windows 10 and 11, 64-bit

    Download for Windows DuckkyClient-Setup.exe

    Linux

    Ubuntu, Fedora, Arch, Mint and most others, 64-bit

    Download for Linux DuckkyClient-linux.AppImage - one file, nothing to install

    1. Open it

      Windows: run DuckkyClient-Setup.exe. Linux: open the AppImage - if it doesn't start, tick "Allow executing as program" in its Properties.

    2. Sign in

      Sign in with the Microsoft account that owns Minecraft: Java Edition.

    3. Press Launch

      Java, Minecraft and the mods download by themselves on the first start.
